🔑 Volvo OAuth Setup

One-time helper to complete Volvo's OAuth authorization-code + PKCE flow and get a refresh_token for the dashboard — without hand-building URLs or copy-pasting a code challenge. Run this once per vehicle/app registration.

1Register this exact redirect URI

In your Volvo developer app settings, set the redirect/callback URI to this page's own URL — Volvo will send the browser back here with the authorization code.

2Scopes

Every scope this dashboard's backend can use, across Connected Vehicle, Energy, and Location — confirmed against a real "Publish application" summary screen. Your app must actually have each of these checked in its own Publish/Edit screen on developer.volvocars.com, or Volvo will reject the whole request with invalid_scope — trim this list to match yours if it's narrower.

3Authorize

Requires VOLVO_CLIENT_ID and VOLVO_CLIENT_SECRET already set as Cloudflare Pages secrets. Clicking this takes you to Volvo's login — sign in as the vehicle owner and grant consent, and you'll land back here automatically.

4Done

Paste this into the VOLVO_REFRESH_TOKEN secret on the Pages project (Settings → Environment variables), then redeploy. If it says it saved directly to the database, that step is optional — D1 already has it.
