It is not affiliated with, endorsed by, or operated by Volvo Cars — it is an independent personal project built against Volvo's publicly documented Connected Vehicle, Location, and Energy APIs.

1. What this is

Volvo Dashboard is a private, single-owner web application for viewing and controlling one specific vehicle belonging to the site owner. It is not a public service, is not offered commercially, and is not intended for use by anyone other than the owner and people the owner explicitly grants access to (e.g. a family member).

2. Access

The application is gated behind an access code known only to the owner and anyone they choose to share it with. Anyone with that code can view the vehicle's status, location, and trip history, and can send it remote commands (lock/unlock, climate control, horn/lights, engine start/stop, where supported). Sharing the access code means sharing that level of control.

3. Data accessed and stored

Through Volvo's APIs, the application reads and may act on:

  • Vehicle status (doors, windows, tyres, warnings, diagnostics, odometer, fuel/battery level)
  • Current and historical location, used to derive a personal trip log
  • Remote commands (lock/unlock, climatization, horn/lights, engine start/stop)

Location history, derived trip data, and manually logged fuel fill-ups are stored in a private database operated by the site owner (Cloudflare D1) for the sole purpose of powering this application. This data is not sold, shared with advertisers, or provided to any third party, except as required to operate the underlying infrastructure (e.g. Cloudflare as the hosting provider) or as required by law.
